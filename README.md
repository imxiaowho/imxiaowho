# 小谁 · 陈震

[元舵 Tunenomics](https://www.tunenomics.com/) 是我的一人公司。最初搭工作台，是想少在几个工具之间传话。现在我想把 Agent 交回来的文件收在一个地方，打开就能核对这件事做完了没有。

我把几次尝试和回退的原因写在《工作台的五段路》里。还有个小演示，可以拿示例任务试一遍。[开发手记](https://imxiaowho.org/workbench-footsteps.html) · [替我值班一分钟](https://imxiaowho.org/workbench-playground.html)

## 我做的工具

- [TuneMeter · 元舵用量计](https://github.com/imxiaowho/tunenomics-tunemeter) 在本机统计 Agent 用量，导出默认脱敏的 ZIP。费用另行核算。目前可以下载[预发布版](https://github.com/imxiaowho/tunenomics-tunemeter/releases)。
- [PaperEncore · 卷土重来](https://github.com/imxiaowho/paper-encore) 把拍照或扫描的练习纸重排成黑白 A4，核对原题后再出打印版。
- [InkAlive · 妙笔生动](https://github.com/imxiaowho/ink-alive) 给插画角色做短 GIF。导出前逐帧看动作，再放一遍检查循环接得顺不顺。

我也在做《School as Usual》，把国际新闻改成校园里的故事。漫画放在[个人站](https://imxiaowho.org/)。
